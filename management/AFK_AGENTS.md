# Active AFK / Cloud Agents

This file describes approved agent work for Cursor Cloud Agents and AFK runs.

Rules:

- Agents may only work on **assigned Work Items** backed by a GitHub Issue.
- Multiple Work Items may be active when Issue scopes do not overlap.
- Agents may not invent additional work.
- Agents must follow `AGENTS.md`.
- Agents stop after completing their assigned Work Item.
- GitHub Draft PRs represent work in progress. **Live PR and CI status belongs to GitHub**.
- A merged PR means the deliverable landed on `main` only after the **founder** merges it.
- Agents create **Draft** PRs and **never merge** to `main`.
- Historical numbered sprints are archived in [`LEGACY_SPRINT_HISTORY.md`](./LEGACY_SPRINT_HISTORY.md). Do not revive the sprint registry.

Canonical procedure: [`docs/DEVELOPER_WORKFLOW.md`](../docs/DEVELOPER_WORKFLOW.md).

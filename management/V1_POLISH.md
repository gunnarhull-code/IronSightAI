# V1 Polish Backlog

This document is a running backlog of small UX, validation, workflow, and quality-of-life improvements that are **not required** to complete core features. These are the kinds of improvements that make a feature feel finished and pleasant to use, but that would slow down or distract from building the core feature itself if tackled in the moment.

Items should be added here whenever we identify friction while using the app — a rough edge, a missing convenience, a "someone will ask for this eventually" moment. Being added to this list is not a promise something will be built immediately; it's a promise it won't be forgotten.

## Rule

Whenever we notice something that makes us think:

- "This feels clunky."
- "Wouldn't it be nice if..."
- "Users will probably expect..."

We should ask:

**Is this a Core Feature or V1 Polish?**

- If it is **Core**: build it now.
- If it is **V1 Polish**: add it to this backlog and continue building the current feature.

The goal is to prevent feature creep while ensuring good ideas are never forgotten.
